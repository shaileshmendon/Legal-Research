# Caselaw Updates

Weekly digest of caselaw relevant to the Finance Command Center (Indian GST / ITC / invoicing, plus adjacent areas as needed).

## Conventions

- One file per week: `YYYY-MM-DD.md` (date = week-ending date). Start from `TEMPLATE.md`.
- Cite only from primary sources (Supreme Court / High Court / GSTAT judgment text, or SCC Online / Manupatra / Taxmann). Secondary summaries are leads, not citations.
- Mark anything not checked against the judgment text as **unverified**.
- If a week has no verified material, say so instead of filling the gap.
